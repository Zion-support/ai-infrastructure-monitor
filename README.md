Ingests server, network and cloud metrics; detects anomalies without static thresholds; correlates alerts to cut noise; forecasts saturation feeding [AI Capacity Planner](https://github.com/Zion-support/ai-capacity-planner); verifies recoverability with [AI Backup Integrity](https://github.com/Zion-support/ai-backup-integrity).

## Key features
- Metric/log/trace ingestion (Prometheus, CloudWatch, Azure Monitor)
- Unsupervised anomaly detection with seasonal baselines
- Alert correlation, incident timelines, Slack/Teams/PagerDuty routing
